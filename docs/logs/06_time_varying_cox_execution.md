# 시변 Cox와 임대료 보조 분석 실행 로그

- 실행: `.venv\Scripts\python.exe src\06_time_varying_cox.py`
- 입력 패널: 73,597행, 점포 7,348개, 사건 3,408건
- 적합: `CoxPHFitter(duration_col="stop", entry_col="start")`, 개업연도 층화, 배정 상권 군집 강건 샌드위치 분산. 이전 실행의 상권 클러스터 부트스트랩(5회·3회)은 반복 수가 부족해 폐기함
- 동일성 확인: 시변 상권+점포 단위 경쟁 모형에서 `CoxTimeVaryingFitter`와의 계수 최대 절대차 7.40e-06(상권 커피 점포 수 결측 표시처럼 우도면이 평평한 변수에서 나는 수렴 허용오차 수준), 부분 로그우도 차 4.33e-10 → 같은 부분우도로 판단(기준: 계수 1e-4, 로그우도 1e-6 이하)
- 결측 제외: 점포 3개, 구간 16개 (`docs/tables/06_tv_cox_excluded_intervals.csv`)
- 표준화: 로그 총매출 평균 23.211664, 표준편차 1.842121; 로그 유동인구 평균 13.879141, 표준편차 1.025500
- 층화: 2026년 사건이 30건 미만이어서 2025년과 합침
- 그림: 맑은 고딕 설정 뒤 `axes.unicode_minus=False`, 로그 축 눈금은 소수 형식으로 직접 지정
- 보고서 `docs/reports/06_time_varying_cox_report.md`는 이 스크립트의 표를 보고 직접 작성함
- 패키지 설치·원자료 수정 없음; 임시 파일은 프로젝트 .tmp/만 사용

# Codex 작업: 개업 시점 고정 변수 Cox 주 분석

CLAUDE.md의 "분석 범위", "정의", "Cox 주 분석 설계"와 AGENTS.md 규칙을 따른다. `.venv`를 쓰고 패키지는 설치하지 말며(lifelines 0.30.3 설치됨, 없는 패키지가 필요하면 보고), 임시 파일은 `.tmp/`에 두고 커밋하지 않는다. 가설은 경쟁·수요·상쇄라는 이름으로만 쓴다. 결과는 "연관된다" 수준으로 서술하고 인과로 쓰지 않는다.

## 입력과 표본
- 입력: `data/processed/cafes_analysis.parquet`
- 주 분석 표본: `is_franchise == False`, `trdar_within_200m == True`. 생존기간 `survival_days`, 사건 `event`.
- `trdar_coffee_stores`, `trdar_coffee_franchise_stores` 결측(커피 점포 행 부재)은 0으로 채우고 `trdar_coffee_stores_missing` 표시 변수를 만든다.
- 그 밖의 투입 변수(총매출·유동인구·상주인구 등)가 결측인 행은 제외하고, 제외 건수와 사유를 단계별로 기록한다. 모든 모형은 같은 최종 표본으로 적합한다(모형 간 비교가 표본 차이로 흔들리지 않게).
- `has_predecessor_same_site`는 넣지 않는다.

## 변수
- 점포 단위 경쟁: `comp_indep_r200`, `comp_fran_r200` (반경 200m 개인 카페 수, 프랜차이즈 수). 기본은 선형 개수로 넣고, 위험비는 1개당과 사분위 범위(IQR)당을 함께 보고한다.
- 수요: `log(trdar_sales_total)`(개업 직전 분기 상권 총매출), `log(trdar_floating_pop)`. 상호작용 해석을 위해 표준화(평균 0, 표준편차 1)한 값을 쓴다. 0 이하 값이 있으면 처리 방법을 보고한다.
- 통제: `log(trdar_resident_pop)`, 상권 구분 `trdar_type`(골목상권 기준 범주형).
- 상권 단위 경쟁: `trdar_coffee_stores`(상권 커피 점포 수)와 결측 표시.
- 층화: 개업 연도. 2026년 층의 사건이 30건 미만이면 2025년과 합치고 그 사실을 기록한다.
- 표준오차: 배정 상권(`trdar_cd_assigned`) 기준 군집 강건 표준오차.
- 적합 전에 투입 변수의 VIF를 다시 계산해 표로 남긴다.

## 모형
모두 개업 연도로 층화한다.
1. **상권 모형**: 상권 커피 점포 수 + 결측 표시 + 수요 두 개 + 상주인구 + 상권 구분. 상권 단위 지표만 쓴 기준 모형이다.
2. **상권 + 점포 단위 경쟁**: 1번에 `comp_indep_r200`, `comp_fran_r200`을 더한다. 1번 대비 우도비 검정, AIC, Harrell's C 차이로 점포 단위 미시 경쟁이 추가로 설명하는지 판단한다.
3. **경쟁만**: 경쟁 두 변수 + 상권 구분. 수요를 넣기 전 경쟁 계수.
4. **경쟁 + 수요**: 3번에 수요 두 개와 상주인구를 더한다. 3번→4번의 경쟁 계수 변화(위험비와 변화율)로 상쇄의 "가려짐"을 본다.
5. **상호작용**: 2번에 `경쟁 합계(comp_total_r200)×표준화 로그 총매출`, `경쟁 합계×표준화 로그 유동인구`를 더한다. 상쇄의 "완충"을 본다. 수요 하위 25%·중앙·상위 25%에서 경쟁 1개당 위험비(신뢰구간 포함)를 계산해 표로 낸다.

## 점검
- **비례위험**: 2번과 5번에 Schoenfeld 잔차 검정을 하고 변수별 p값을 표로 남긴다. 경쟁이나 수요 변수가 위반되면, 개업 후 1년 이내와 이후로 나눈 시간 구간 상호작용 모형을 추가로 적합해 두 구간의 위험비를 보고한다(KM에서 고경쟁·고매출 집단이 개업 초기에 먼저 떨어지는 모습이 보였다).
- **프랜차이즈 경쟁 비선형성**: 2번에서 `comp_fran_r200`을 0 / 1–2 / 3–5 / 6개 이상 구간 더미로 바꾼 모형을 함께 적합한다.
- **관광특구 제외 민감도**: 관광특구를 뺀 표본으로 2번과 5번을 다시 적합한다.
- **0 채움 점검**: 2번에서 상권 커피 점포 수 결측 470건을 뺀 모형과 계수를 비교한다.

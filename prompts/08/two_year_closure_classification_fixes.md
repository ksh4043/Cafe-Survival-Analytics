# Codex 작업: 2년 폐업 분류 비교의 기준값 방식 수정

`prompts/08/two_year_closure_classification.md` 작업 결과(`src/08_closure_classification.py`)를 고친다. CLAUDE.md·AGENTS.md 규칙은 그대로 따른다. 패키지 설치 금지, 임시 파일은 `.tmp/`.

## 문제

학습 겹 F1 최대 기준값이 거의 모든 모형에서 "모든 점포를 폐업으로 예측"으로 퇴화했다(2년: 정확도 0.334, 재현율 1.0, 모든 모형 F1 0.500). 이래서는 모형별 정확도·정밀도·재현율 비교표가 모형 차이를 보여 주지 못한다. 또 XGBoost만 클래스 가중치가 없어 0.5 기준 재현율이 0.01~0.06으로, 0.5 기준 표에서도 다른 모형과 비교 조건이 다르다.

## 고칠 것

1. **주 결과의 기준값**: 학습 겹의 폐업 비율만큼 위험 상위 점포를 폐업으로 예측한다. 즉 학습 겹 예측확률(내부 교차검증 OOF)의 `1 − 학습 겹 폐업 비율` 분위수를 기준값으로 정해 평가 겹에 적용한다. 모든 모형이 같은 비율을 폐업으로 예측하므로 정확도·정밀도·재현율을 공정하게 비교할 수 있다. 다수 클래스 기준선은 그대로 두고, 개업 연도 로지스틱도 같은 방식으로 한다. 예측값이 동점이라 분위수로 비율을 맞추기 어려운 모형(개업 연도만, 얕은 나무)은 실제 예측 폐업 비율을 표에 함께 적는다.
2. **XGBoost 클래스 가중치**: 다른 모형과 맞추려 학습 겹마다 `scale_pos_weight = 생존 수 / 폐업 수`를 준다.
3. **부록 표**: 0.5 기준 결과(`08_clf_threshold_05_performance.csv`)는 수정된 XGBoost로 다시 만든다. F1 최대 기준 결과는 `08_clf_threshold_f1max_performance.csv`로 남기고, 보고서 부록에서 "모두 폐업으로 예측하는 쪽으로 퇴화했다"는 점을 한 줄로 설명한다.
4. **가장 나은 모형 선정**: F1이 아니라 ROC-AUC 평균으로 고른다(기준값과 무관한 지표). 혼동 행렬 그림은 그 모형을 주 기준값으로 그린다.
5. **변수 중요도 서술**: 순열 중요도(평가 겹 ROC-AUC 감소)를 주 지표로, 평균 |SHAP|은 보조로 둔다. 순열 중요도의 평균이 표준편차보다 작은 변수가 대부분이면 "모형의 구분력 자체가 낮아 변수 순위가 불안정하다"고 분명히 적고, 생존 머신러닝(`docs/tables/08_ml_*` 중요도)·Cox 결과와 일치하는 점과 다른 점을 함께 적는다. 보고서 양식용 "1순위·2순위 중요 변수" 문장은 순열 중요도 기준으로 쓰되 이 불안정성을 같은 문장 근처에 적는다. 중요도 그림도 순열 중요도 기준으로 바꾸고 겹 간 표준편차를 오차막대로 넣는다.
6. 성능 비교 그림, ROC 그림, 1년·3년 표, 보고서·실행 로그를 새 결과로 다시 만든다. 하이퍼파라미터 고정값은 그대로 둔다.

# Codex 작업: 단계 그림 수정과 주제 밖 그림 정리

`prompts/report/stage_figures.md` 작업의 결과(`src/report_figures.py`, `docs/figures/02_*`, `03_*`, `docs/figures/README.md`, 02·03 보고서의 그림 삽입)를 고친다. AGENTS.md의 그림 규칙(주제·목표에 관련된 그림만, 보고서 삽입 방식, 색)을 따른다. `.venv`를 쓰고 패키지는 설치하지 말며, 임시 파일은 `.tmp/`에 둔다. 05·06 단계 파일은 다른 작업이 수정 중이므로 건드리지 않는다.

## 1. 주제 밖 그림 삭제
연구 질문(카페 생존과 입지·경쟁 환경)에 답하지 않는 처리 과정 그림이라 뺀다. 스크립트에서 생성 코드, PNG 파일, 보고서 삽입, README 행을 모두 지운다.
- `02_franchise_brands.png`
- `03_trade_area_distance.png` (200m 기준 포함·제외 비율은 보고서 본문 문장으로 남긴다)
- `03_covariate_correlation.png` (상관·VIF는 표로 충분)
`03_competition_distribution.png`는 남기되 README 용도를 "부록(반경 강건성 설명용)"으로 바꾼다.

## 2. 그림 수정
- `02_sample_flow.png`: 첫 화살표가 거꾸로("<") 그려지고 첫 두 상자가 붙어 있다. 상자 간격을 일정하게 하고, 단계 사이 제외 건수는 해당 화살표 바로 위·아래에 사유와 함께 붙인다(지금처럼 위에 숫자만 떠 있고 사유는 아래에 따로 모아 두지 않는다). 위아래 빈 공간을 줄인다. "카페 정제"처럼 모호한 단계명은 실제 기준(한시적·0일 이하·카페가 아닌 업종 제외)이 드러나게 바꾼다. "개업 기간 → 개인 카페" 단계는 프랜차이즈 3,463개가 경쟁 환경 계산에는 남는다는 점을 짧게 적는다.
- `03_cafe_map.png`: 점이 너무 많아 영업 중/폐업 구분이 보이지 않아 정보가 없다. 다음 그림으로 바꾼다. 파일명 `03_closure_vs_density_map.png`, 좌우 두 패널, 같은 육각 격자: 왼쪽은 격자 내 개인 카페 수(지금 `03_competition_density_map.png`와 같은 값), 오른쪽은 격자 내 개인 카페의 폐업 비율(점포 10개 미만 격자는 회색 처리, 그 기준을 그림에 표기). 관측 기간이 점포마다 달라 단순 폐업 비율은 생존 분석이 아니라는 점을 주석으로 한 줄 적는다. 기존 `03_cafe_map.png`와 `03_competition_density_map.png`는 삭제하고 보고서·README를 새 그림으로 바꾼다.
- `03_competition_vs_demand.png`: 상권 총매출 패널 옆에 로그 유동인구 패널을 추가해 두 패널로 만든다(Cox에서 완충이 유동인구에서만 보였으므로 둘 다 필요). 각 패널에 상관계수를 표기한다. y축 단위 표기는 실제 변환과 맞춘다.
- `02_openings_closures_by_quarter.png`: 범례가 "개업 기간 종료"·"관측 종료" 표시 글자와 겹친다. 범례를 그림 밖(위쪽 한 줄)으로 빼고 기준선 표시 글자가 막대·범례와 겹치지 않게 한다. 2026년 3분기 폐업 막대가 관측 종료 분기라는 점이 헷갈리지 않게 표시한다.

## 3. 확인
- 모든 그림을 열어 글자 겹침, 잘림, 거꾸로 된 화살표가 없는지 직접 확인하고 실행 로그에 적는다.
- 보고서의 그림 링크가 모두 실제 파일을 가리키는지, 지운 그림을 가리키는 링크가 남지 않았는지 확인한다.
- `docs/figures/README.md`를 갱신한다.
